# ♞ Разбор партий

Сайт для разбора шахматных партий в стиле «Отчёта о партии» chess.com. Работает целиком в браузере: Stockfish 19 (WASM) считает на вашем компьютере, сервер не нужен.

## Возможности

- Импорт партий с **chess.com** и **lichess** по нику или вставка **PGN**
- Классы ходов: блестящий `!!`, отличный `!`, лучший, превосходный, хороший, теория, вынужденный, неточность `?!`, ошибка `?`, промах, зевок `??`
- Точность игроков (формула lichess), счётчики по классам
- Тренер с комментариями, стрелка лучшего хода, лучший вариант
- Шкала и график оценки, ключевые моменты
- Режим «Повторить»: найдите лучший ход сами
- Название дебюта (база lichess-org/chess-openings)
- Кэш разборов в браузере, тёмная тема, мобильная вёрстка

## Как классифицируются ходы

Оценка движка переводится в вероятность победы `Win% = 50 + 50·(2/(1+e^(−0.00368·cp)) − 1)`. Потеря шансов на ходу:

| Класс | Условие |
|---|---|
| Теория | позиция есть в базе дебютов (подряд с начала партии) |
| Вынужденный | единственный легальный ход |
| Блестящий | лучший или почти лучший ход (потеря < 2%) с жертвой фигуры; после хода шансы ≥ 45% |
| Отличный | лучший ход, а второй вариант хуже на 15%+ (единственный ход) |
| Лучший | совпадает с первой линией движка |
| Превосходный / Хороший | потеря < 2% / < 5% |
| Неточность / Ошибка / Зевок | потеря < 10% / < 20% / ≥ 20% |
| Промах | соперник только что ошибся (≥ 10%), а вы потеряли ≥ 8%, но позиция не проиграна |

Пороги находятся в `src/lib/classify.ts`.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm test           # прогон анализа «Оперной партии» в Node
```

Деплой на GitHub Pages идёт автоматически при пуше в `main` (`.github/workflows/deploy.yml`).

## Структура

- `src/lib/engine.ts` — UCI-обёртка над Stockfish (Web Worker)
- `src/lib/analyze.ts` — анализ партии, точность, лучшие линии
- `src/lib/classify.ts` — классификация ходов и комментарии тренера
- `src/lib/importers.ts` — API chess.com и lichess
- `src/components/` — интерфейс (доска, шкала, график, список ходов, сводка)
- `scripts/build-openings.mjs` — сборка базы дебютов из TSV lichess
